# EgyDose v8.0
### An Independent Radiotherapy Education Simulator

EgyDose is an independent, browser-based educational project designed to explore fundamental concepts in medical physics, with a particular focus on radiotherapy dose calculations and treatment-planning principles.

Developed using HTML, CSS, and JavaScript, EgyDose provides an interactive learning environment for exploring radiation dose physics, treatment parameters, and IMRT-related concepts.

The project was initiated as a personal effort to bridge theoretical knowledge in medical physics with computational tools and interactive learning. Claude was used as an AI-assisted coding tool throughout the development process.

**Key areas of exploration:**
- Fundamental radiotherapy dose calculations.
- Radiation physics and dosimetric concepts.
- Treatment-planning parameters.
- IMRT-related educational concepts.
- Interactive visualization and learning.

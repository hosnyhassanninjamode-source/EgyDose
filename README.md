Welcome to EgyDose
EgyDose was created as a personal learning project to make selected radiotherapy and medical-physics concepts easier to explore interactively. It brings together an interest in biophysics, medical physics, and computational tools.

The project is intended for students, educators, and curious learners who want to explore the concepts presented in the application. It is a learning aid—not a clinical tool.

How to use EgyDose
 — Download it from GitHub
You do not need to know how to code to try the project.
1. At the top of this GitHub repository, select the green Code button.
2. Choose Download ZIP.
3. When the download finishes, extract the ZIP file to a folder on your computer.
4. Open the extracted folder and locate index.html.
5. Double-click index.html to open it in your browser.
Important: Download the entire repository—not just index.html—and keep the files and folders together. The page may need its accompanying assets or scripts to work correctly.

If opening the file directly does not work as expected, try the live demo (when available). Some browser features or local-file restrictions may require the project to be served through a local web server.
Option 3 — Explore the source code
You can browse the files directly on GitHub to see how the project is organised. To work with your own local copy, use Code → Download ZIP, or clone the repository if you are comfortable with Git.
What does it explore?
EgyDose provides an interactive way to explore selected topics covered by the application, including:
- Radiation dose physics: introductory dose-calculation concepts and relationships.
- Treatment-planning concepts: selected treatment parameters and their educational context.
- IMRT concepts: interactive exploration of selected intensity-modulated radiotherapy concepts.
- Interactive learning: a browser-based way to experiment with the controls and observe the application's outputs.
The exact scope is limited to the features implemented in this version. The presence of a calculation or visualisation does not mean that it has been validated for clinical accuracy or suitability.
